## 4. Boundary Screen GUI

### 4.1 목적

AC-FR-01-01 GREEN 직후 **수동 GUI 확인** — pytest와 동일 `code` / `message` 표시 (교육 GREEN 워크플로 Step 4).

### 4.2 구조 (ECB)

| 경로 | 역할 |
|---|---|
| `src/boundary/screen/app.py` | Tkinter UI — `BoundaryValidator`, Control `solution()` 위임 |
| `src/boundary/screen/grid_input.py` | 4×4 Entry → grid 파싱 (`GRID_SIZE=4`) |
| `src/boundary/screen/__main__.py` | `python -m src.boundary.screen` |
| `boundary/screen/app.py` | **`python -m boundary.screen.app`** 런처 (교육 템플릿 명령) |
| `boundary/screen/__main__.py` | `python -m boundary.screen` |

**의존 방향:** Screen → `BoundaryValidator` (동일 Boundary) · Solve → `src.control.use_cases` (Entity 직접 호출 없음).

### 4.3 UI 기능

| 버튼 | 동작 |
|---|---|
| Validate | `BoundaryValidator.validate(grid)` → `code` / `message` 표시 |
| None Grid (AC-FR-01-01) | `validate(None)` → `INVALID_SIZE` / `Grid must be 4x4.` |
| Solve | validator 통과 후 `solution(grid)` |
| Load G1 | G1 샘플 격자 로드 |
| Clear | 입력 초기화 |
