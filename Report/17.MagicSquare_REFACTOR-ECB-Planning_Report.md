### 4.1 추가 판단

- **solve_partial → Entity vs Control:** 혼재. Control은 locate→find→solve **오케스트레이션만**, 알고리즘은 `two_cell_solver`(Entity).
- **ui_boundary must_not:** Domain 알고리즘 직접 호출 없음(양호). E001 code drift·E006/E007·int[6] 직렬화 부재.
- **main_window UI 외 책임:** 검증 게이트, Control 직접 호출, `code=`/`SOLVE_ERROR` 직렬화, `_G1_SAMPLE` fixture 포함.
