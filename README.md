# MagicSquare_XX

4×4 마방진(Magic Square)을 다루는 프로젝트입니다.  
현재 단계는 **문제 정의(Problem Definition)**이며, 구현·설계·코드는 아직 시작하지 않았습니다.

---

## 프로젝트 한 줄 요약

**4×4 격자에 1~16을 한 번씩 배치했을 때, 정해진 줄(행·열·대각선)의 합이 모두 같은지를 명시된 규칙으로 판정하고, 그 판정을 같은 기준으로 반복 적용할 수 있게 하는 것**이 핵심 문제입니다.  
(필요 시, 규칙을 만족하는 완전한 배치 하나를 제시할 수도 있습니다.)

## 표면 정의 vs 진짜 문제

| 구분 | 내용 |
|------|------|
| **표면 정의 (피해야 할 표현)** | 「4×4 마방진을 만드는 프로그램을 만든다」 |
| **문제점** | 생성/검증/표시가 섞이고, 성공 기준·주체가 없음 |
| **진짜 문제** | **규칙 만족 여부의 판정**과 그 **재현** — 완성된 격자 산출만이 목적이 아님 |

## 핵심 Invariant (불변 조건)

### 도메인 (완전히 채워진 격자)

| ID | 불변 |
|----|------|
| I-1 | 크기: 4×4 |
| I-2 | 값: 1~16이 각 칸에 정확히 한 번 (중복·누락·범위 밖 없음) |
| I-3 | 마법 상수: 관련 있는 모든 줄의 합이 같음 (**34**) |
| I-4 | 관련 줄: 최소 4행 + 4열 + 2대각선 *(범위는 요구에 따라 고정)* |

**유효한 완성 상태** = I-1 ~ I-4를 **동시에** 만족.

### 판정·시스템

| ID | 불변 |
|----|------|
| I-5 | 같은 배치 → 같은 유효/무효 (결정성) |
| I-6 | 유효 판정 시 I-2·I-3·I-4를 빠짐없이 검사 |
| I-7 | 「유효」는 16칸이 모두 채워진 배치에만 적용 |
| I-8 | 4×4·1~16·합 34·줄 범위가 바뀌면 **다른 문제** |

### 정책 (불변 아님 — 나중에 선택)

- 어떤 유효한 배치를 대표로 보여줄지  
- 해를 몇 개 나열할지  
- 힌트·부분 채움 UX

## Why 요약 (왜 이렇게 접근하는가)

| 단계 | 질문 | 핵심 |
|------|------|------|
| **Why #1** | 왜 완성해야 하는가? | 규칙 만족을 **확인·제시**하기 위함 — 단, 「완성」과 「검증」을 구분할 것 |
| **Why #2** | 왜 프로그램인가? | **반복 가능성**, **검증 자동화**, **오류 방지**, **규칙 기반 사고** |
| **Why #3** | 왜 TDD로 설계하는가? | **판정 명세**를 먼저 고정하고, 불변·입출력 계약으로 요구 혼선을 줄이기 위함 |

```
관찰 → Why #1 → Why #2 → Why #3 → 진짜 문제 정의
```

## 훈련하려는 사고 능력

- 규칙을 검사 가능한 조건으로 **명시화**
- **불변**과 **정책(선택)** 구분
- 결과 그림보다 **판정**(유효/무효) 중심 사고
- 입력·출력 **계약** 합의 (완전 채움 vs 미완성)
- 같은 기준의 **반복 가능한** 판정
- 한 조건만 맞아도 전체는 실패일 수 있는 **부분–전체** 연결

> 조건을 말로 고정하고, 빠짐없이 적용해 판정하며, 판정이 바뀌지 않게 유지하는 사고.
